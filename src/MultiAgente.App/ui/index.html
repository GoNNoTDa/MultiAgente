Consumo y límites

Cuánto ha gastado cada cuenta. Las suscripciones de Claude informan de su bloque de 5 horas y de su límite semanal; el mes es el coste que informan los agentes frente al presupuesto que pongas. La marca de cada barra es donde el equipo pasa a otra cuenta.

Extensiones

Lo que pongas aquí lo usan todas tus cuentas (y, cuando el formato lo permite, Claude Code, Codex y Gemini a la vez). Los cambios valen para las sesiones que se abran a partir de ahora.

Servidores MCP

Herramientas externas (GitHub, bases de datos, navegador…). MultiAgente se las pasa a cada sesión: no se toca la configuración de cada agente. Las claves se guardan cifradas.

Skills

Instrucciones especializadas que el agente carga cuando las necesita (formato SKILL.md). Una sola carpeta para Claude Code, Codex y Gemini.

Plugins de Claude Code

Se instalan una vez con /plugin en cualquier sesión de Claude y quedan para todas tus cuentas de Claude. Aquí se activan o desactivan.

Instrucciones comunes

Normas para todos los agentes y cuentas: se añaden al CLAUDE.md, AGENTS.md y GEMINI.md de cada cuenta en un bloque marcado. Lo que cada agente recuerde por su cuenta se conserva y se comparte entre las cuentas de su proveedor.

Cuentas y proveedores

Cada cuenta tiene su propia carpeta dentro de datos\cuentas. Tu configuración de siempre (~/.claude, ~/.codex, ~/.gemini) no se toca. Las claves se guardan cifradas en la carpeta de MultiAgente.

Equipos

Un equipo reparte las sesiones «Automático» entre sus cuentas y, cuando una se agota, pasa la sesión a la siguiente con margen sin perder el hilo (mismo proveedor: la misma conversación; otro: con un resumen de lo hecho).
